## What held up

- **The package's layout and control data** (A):
  - paths, modes and root:root are right;
  - the control file is well-formed, the changelog parses and md5sums verify;
  - two builds on one file system are the same bytes.
- **The scripts under the real dpkg** (A): install, remove, purge and an upgrade call
  them in the right order, as `dh_installsystemd` would. They are safe to run again.
- **The hand install's marks** (A, B): they are in every hand install since `m2`.
  `NAME.dpkg-old` is passed over by grub-mkconfig, systemd and PATH.
- **The version's order at the tags** (A).
- **The lab's reset fix `7bbaa82`** (B): it only chains a guest RESET that a fast
  reader would have chained, and it blocks for 30 s at most.
- **D.4 is a real first install** (B): D.3's purge leaves none of
