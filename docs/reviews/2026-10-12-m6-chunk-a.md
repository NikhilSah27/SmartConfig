## What held up

- **The guest record.**
  - Every copy in `eval/guest/` matches both reference images byte for byte.
  - Modes, owners, absent paths and facts match the image.
  - Nothing comes from this VM: no user name, interface name, UUID or machine-id.
- **The catalogue.**
  - All 45 pilot cases are in it, and each `source` matches Appendix A.
  - Each pattern hits only the line or lines it means to.
  - Each incident is the change it says, by its consumer's own tool: `sshd -T`, `visudo -c`,
    `netplan generate`, `udevadm verify`, `sysctl --dry-run`, and dash sourcing the GRUB files under
    `set -e`.
  - The GRUB incidents avoid the keys the image overrides.
  - Apart from A5, no incident cuts ttyS1, `console=ttyS0` or the root shell.
- **The neutral mutants.** 2506 of them (three seeds, 120 a file) of the image's 25 checked files read the
  same as the stock file to the real parsers.
- **The factory's mechanics.**
  - It is deterministic, and a file's mutants depend only on the seed and that file.
  - The cap and the dedupe hold.
  - Mode and owner mutants are made for the sudoers paths only.
  - A dash `read -r` loop read the full image's `manifest.tsv` (1036 rows) with every sha256 right.
- **`surfaces()`** otherwise matches the Go code: sc edit keeps the mode and owner, scd checks file rows
  only, `sc check` refuses a link, and the scope leaves out `/etc/sudoers.d/*.*`.
