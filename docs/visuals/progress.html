Roadmap

Seven milestones, one done

    How it was built

    Built in seven minutes, then hardened for almost five hours

    The code for M1 went in between 00:04 and 00:11. In the evening, M2 research found two weak spots, and four review rounds followed. Most of the growth after that is tests: almost every code fix came with a new test, most of them shown to fail on the old code.

    How it was checked

    Four review rounds, 54 findings, none rated high by the skeptics

    Each round: reviewer agents ran the real code and tried to break it; two skeptic agents per finding tried to prove the reviewer wrong. A finding is confirmed when both skeptics agree it is real: 53 of the 54 were, and one was a split vote. No skeptic rated any finding high (one reviewer rated the symlinked-parent-directory finding high; it is deferred to M2). Rounds 3 and 4 found no data loss on this VM; round 3 found one narrow case on filesystems with coarse timestamps (vfat, ext4 with 128-byte inodes), left as a known limit.

    What exists today

    What sc does, and what makes it safe

    Commands

    sc initCreate the private store ($SC_HOME, default /var/lib/smartconfig)
    sc snapshot <path>Save a file's content, mode and owner, with an optional reason (-m); an unchanged file is not saved twice
    sc log [path]List the saved versions, newest first (50 by default; -n 0 for all)
    sc cat <id>Print a saved version exactly
    sc diff <id> [id2]Show what changed against the file on disk, or between two versions
    sc restore <id>Put a version back with its mode (including setuid, setgid and sticky) and owner; the current state is saved first

    Guarantees, checked by the tests and the release check

    • A restore can be undone: the file's current content, mode and owner are saved and committed before it is replaced (limits in MILESTONES.md)
    • The new version is written and fsynced to a temp file first, then renamed over the file in one step; the file is never written in place
    • A file swapped for a symlink or FIFO is refused, never followed or blocked on (symlinked parent directories are left to M2)
    • A corrupted saved copy is detected and never restored
    • Ctrl-C stops at a safe point and says whether the file changed
    • One static binary with no shared libraries (release check with file and ldd, not a test), so a broken libc or loader cannot stop it
