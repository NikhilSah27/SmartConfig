    What is realMilestone 1 scenes use the real output of sc recorded on this VM. The boot failure is based on running systemd's own fstab generator against the broken file on this VM: the /data mount requires the missing disk, so boot waits 90 s and stops. The root account on this VM is locked, as on every default Ubuntu install.
    What is a mock-upEverything tagged concept shows milestones 2 to 7, which are not built yet: the watcher, checkers, rescue boot entry, package and sc why. Their commands and messages are the current design and may change.
    About the clockThe downtime counter in "Without SmartConfig" is illustrative: how long it typically takes someone at the machine to find the cause from Ubuntu's emergency shell, which opens without a root password but says nothing about what changed. Over SSH, someone has to go to the machine.
