    This really happenedEvery command, id and output line comes from a run on this VM at 08:26 on 27 Sep 2026. /etc/fstab was really broken and really restored; cmp confirmed it identical.
    Where the system calls come fromThey were captured with strace on the real sc snapshot and sc restore. Paths are shortened and a few calls are grouped so they fit; the SQL lines (in violet) are what SQLite does between them.
    What M1 can't do yetHere you snapshot by hand and restore before rebooting. The watcher (M2) will snapshot edits automatically, and the rescue boot (M4) will let you restore after the machine fails to start.
